# RSI R2 — counterfactual replay of the automatically mined checks on held-out tasks (airline, 2026-10-30)

Episodes: every logged airline episode of a held-out task (relative to the fold the check was mined on) where one of
the 4 transferring R1 checks fires — 31 episodes (30 failed, 1 successful) from 7 tasks (`r2_flagged.json`). Each is
cut right before the flagged assistant message and continued once per arm by τ²-bench (HEAD 0c69df4), DeepSeek direct,
seed 400. Both arms run the E4 configuration (deliberate + reasoner at Jev p < 0.8, certified rules, consistency
checks); the treated arm adds the 4 mined checks as soft review triggers (`src/gdopt/adapters/tau2_mined.py`; a fire
regenerates the step with deepseek-reasoner and a note built from the check's description and clause).

| arm | success |
| --- | --- |
| control (E4 config) | 5 / 31 (16%) |
| + 4 mined checks | 12 / 31 (39%) |

Paired by episode: treated better 7, control better 0 (sign test, two-sided p = 0.016). The one successful episode
succeeds in both arms. Mined checks fired 33 times in the treated arm.

By check (treated vs control successes / episodes): paid bags only if the user asked for a number of bags 8 vs 2 / 16;
no duplicate booking of an un-cancelled basic-economy reservation 3 vs 2 / 12; payment-method count 0 vs 0 / 2;
certificate only after change/cancel 1 vs 1 / 1. By task: 21 7 vs 2 / 13, 14 2 vs 1 / 8, 17 1 vs 0 / 3, 31 1 vs 1 / 3,
38 1 vs 1 / 1, 23 0 vs 0 / 2, 45 0 vs 0 / 1.

Caveats: one continuation per episode per arm; 13 of 31 episodes and 5 of the 7 wins come from task 21; the replay
starts at a step where the check fires, so it measures rescue given a fire, not the net effect on pass^k (that needs a
full run, where the checks can also fire in episodes that would have succeeded — in the logs they did once in 4048).

Cost: DeepSeek ¥1.15 including a 2-episode pilot (6269.80 → 6268.65), Jev $0.087 (OpenRouter usage 16.379 → 16.466).

Run: `PYTHONPATH=<tau2-bench>/src:src python examples/tau2_rule_replay.py --audit reports/rsi/r2_flagged.json
--anchor-modes deliberate,reasoner --control-extra-modes rules,consistency --extra-modes rules,consistency
--mined reports/rsi/r1.json --include-success --rule-trials 1 --control-trials 1 --out reports/rsi/r2-replay`
